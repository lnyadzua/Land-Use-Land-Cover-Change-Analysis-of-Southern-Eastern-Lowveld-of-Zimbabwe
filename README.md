# Land-Use-Land-Cover-Change-Analysis-of-Southern-Eastern-Lowveld-of-Zimbabwe
This project assesses human-conservation conflict in Zimbabwe's Southern Eastern Lowveld. Analysing human activities vs. conservation efforts, it maps changing agricultural patterns near forests. Insights into issues like charcoal burning and sustainable energy sources emerge. The maps also spotlight potential conflicts from both small and large-scale agriculture, impacting humans and wildlife. 
The analysis of the project was conducted using ENVI software using a Support Vector Machine algorithm for analysis to determine the changes and trends in the areas resulting in human and wildlife conflict.
